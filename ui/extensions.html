Extensions

Add Chrome extensions to Wisp. They run on the same engine as Microsoft Edge, so they work like they do in Chrome.

Extensions are turned off in private windows.

In the Chrome Web Store, the Add to Chrome button reads Add to Wisp. Wisp shows what an extension can access before anything is installed.

Installed

Popular extensions from the Chrome Web Store

Extensions keep their Chrome Web Store ID, settings and sign-ins, and are shared by every space. Open an extension from the puzzle button next to the menu, or pin it to the toolbar.

Wisp uses Microsoft’s WebView2 engine. A few Chrome-only features (such as Chrome’s side panel or Google account sync) aren’t available to extensions.
